# 孩子学习冒险基地 V2.0

面向小学阶段家庭的游戏化学习工作台。本版本把原有的徽章、星星、金币、地图和预习奖励统一重构为 **成长激励系统 V2**：孩子不仅看到“完成了多少任务”，还可以看到自己正在长出哪些具体能力。

## 快速开始

解压后双击：

```text
START_HERE.html
```

需要使用本地 Mock API 或接入模型时，在项目目录运行：

```bash
node server.mjs
```

然后打开终端显示的本地地址。

## 成长激励系统 V2

### 三个核心成长资源

- **经验值 XP**：决定孩子等级与称号，只累计、不消费。
- **成长星**：代表有学习证据的有效成长，用于点亮地图、解锁区域与里程碑，只累计、不消费。
- **探索币**：可以消费的奖励货币，用于兑换 Dino 配件、主题皮肤、地图装饰和家庭奖励。

旧版宝石与徽章碎片不再作为主要资源展示。地图钥匙保留为特殊里程碑奖励。

### 七大能力分类

1. 学习习惯
2. 思考能力
3. 表达沟通
4. 学科学习
5. 自主学习
6. 创造项目
7. 里程碑

首发内置 26 个能力徽章，例如：

- 坚持小勇士
- 时间小管家
- 提问小侦探
- 思路小工程师
- 口语小能手
- 数学思考家
- 预习探险家
- 作品小创客
- 七日坚持勋章
- 学习冒险家总勋章

### 三个成长阶段

- **萌芽**：刚开始尝试，形成能力起点。
- **成长**：持续实践，能力正在积累。
- **闪耀**：表现稳定，达到阶段性里程碑。

每个徽章拥有独立的行为证据和进度，不再通过统一“徽章碎片”兑换。

## 页面联动

### 首页

- 学习日历
- 今天的学习冒险
- 本周任务追踪
- 预习单快捷入口
- 成长地图预览
- 最近任务
- **今日可点亮能力**：显示距离升级最近的三个能力目标

### 今日任务

任务卡明确展示：

- 经验值奖励
- 探索币奖励
- 有效学习证据可获得的成长星
- 本任务主要推动的能力徽章

家长安排任务时选择主要培养能力，成长星由系统根据学习证据发放，避免手动刷分。

### 预习单

完整保留六步互动流程：

1. 看全貌
2. 测基础
3. 想明白
4. 验理解
5. 练迁移
6. 定重点

完成完整预习会推动：

- 预习探险家
- 提问小侦探
- 思路小工程师
- 规律发现家
- 对应学科能力徽章

并发放 XP、成长星和探索币，所有奖励进入奖励流水，避免重复领取。

### 成长地图

地图区域解锁由两类条件共同决定：

- 成长星达到要求
- 对应能力徽章达到指定阶段

地图页显示每个区域关联的能力徽章、缺失条件和下一步建议。

### 成长档案

重构为完整能力徽章中心：

- 已点亮徽章
- 闪耀徽章
- 本月新点亮
- 最近升级
- 今日可点亮能力
- 七大分类徽章墙
- 最近点亮时间线
- 区域成就
- 成长奖励流水
- 家长中心与 AI 服务设置

## 防刷与安全规则

- 同一个任务只能领取一次奖励。
- 专注挑战设置每日奖励上限。
- 成长星必须绑定学习证据、完整预习、实验记录或作品等有效行为。
- 探索币消费进入兑换记录。
- 正式部署时 API Key 应放在服务端代理，不应保存在浏览器。

## 数据迁移

应用会自动迁移旧版本地数据：

- `stars` → `growthStars`
- `coins` → `exploreCoins`
- 旧徽章解锁状态 → 新徽章进度
- 旧任务奖励字段 → 新奖励结构

保留原有 localStorage key，以便用户升级后延续已有数据。
