# 孩子学习冒险基地 V3.0 Alpha

[中文](README.md) | [English](README_EN.md)

> 根据孩子的年级、教材课程包、兴趣主题与学习节奏，创建这个学期专属的学习冒险基地。

**V3.0 Alpha** 的重点不是直接把 AI 变成“自动生成整本教材内容”的黑盒，而是先完成平台化基础：把工作台、教材内容、孩子个性化配置和学习进度彻底解耦，让普通家长可以通过课程包快速创建属于自己孩子的学习工作台。

---

## V3.0 为什么要重构

V2.0 已经具备：首页、今日任务、六步预习单、成长地图、成长档案、能力徽章和成长激励系统等完整体验，但教材内容仍然以“五年级数学示例”为主。

V3.0 开始解决一个更重要的问题：

> **如何让不同家庭，不改代码，也能把这套工作台变成自己孩子、自己年级、自己教材版本的学习基地？**

因此 V3 的核心公式是：

```text
专属学习冒险基地
=
通用工作台 Shell
+
教材课程包 Curriculum Package
+
学段教学适配器
+
孩子个性化覆盖层
+
学习运行状态
```

教材决定“学什么”，学段适配器决定“怎么学”，兴趣主题决定“以什么氛围学”，学习运行状态负责记录孩子真实的成长过程。

# V3.0 Alpha 已实现

## 1. 首次创建学习基地向导

第一次使用时，家长可以直接创建孩子自己的学习基地，而不是进入固定的“五年级数学 Demo”。

可配置：

- 孩子昵称；
- 当前年级；
- 每日学习时长；
- 每周学习日；
- 兴趣偏好；
- 恐龙、赛车、宇宙、海岛等主题；
- 轻松 / 标准 / 进阶学习节奏；
- 少提示 / 逐步提示 / 更多拆解提示；
- 当前年级可用的教材课程包。

正式创建新基地后，孩子的任务、成长数据和学习进度从自己的档案开始记录。

同时保留“快速体验内置示例”，方便第一次打开项目的用户直接查看完整成品效果。

---

## 2. Curriculum Package V3 课程包体系

V3.0 最重要的变化，是**教材内容不再写死在网页核心代码里**。

每一本教材都可以被封装成独立的课程包：

```text
curriculum-package/
├── manifest.json
├── textbook.json
├── curriculum.json
├── units/
│   └── unit-xx.json
├── quality/
│   ├── source-map.json
│   └── review-report.json
└── README.md
```

统一数据规范：

```text
schemas/curriculum-package-v3.schema.json
```

课程包与孩子数据相互独立，因此：

- 同一个课程包可以服务多个孩子；
- 切换教材不需要修改前端代码；
- 导出课程包不会带出孩子姓名、头像和学习记录；
- 后续可以建立课程包社区和版本管理。

## 3. 课程包库与教材中心

V3.0 新增课程包管理能力，支持：

- 查看课程包年级、学期和教材版本；
- 查看课程包可信状态；
- 安装课程包；
- 多教材并存；
- 切换当前教材；
- 切换当前单元；
- 导入本地课程包；
- 导出课程包；
- 将课程包、孩子档案和学习进度分离管理。

课程包可以标记不同可信状态，例如：

- 官方维护；
- 社区已审核；
- 内置演示；
- AI 生成待复核；
- 仅个人使用。

## 4. 两个可切换的数学演示课程包

当前 Alpha 版本内置两个数学课程包，用于验证同一套工作台可以适配不同年级、不同教材内容：

### 五年级下册示例

```text
pep-math-g5-s2-demo
```

包含原有《分数的意义和性质》六步预习内容。

### 四年级上册架构示例

```text
pep-math-g4-s1-demo
```

包含《角的度量》六步交互内容，用于验证跨年级课程包切换。

> 四年级示例包属于“AI 辅助生成 · 待教材复核”的架构演示数据，不应被视为已经完成正式教材审核的课程内容。

## 5. 通用六步预习播放器

六步预习法继续作为项目核心学习机制：

```text
看全貌
→ 测基础
→ 想明白
→ 验理解
→ 练迁移
→ 定重点
```

V3.0 中，六步预习播放器不再绑定五年级数学，而是读取当前激活课程包的统一数据结构。

当前保留：

- 可点击知识地图；
- 两道前置小测；
- 逐步苏格拉底式引导；
- 认一认 / 说一说 / 用一用；
- 母题与一题三变；
- 错因记录；
- 课堂重点；
- 1—3—7 复习计划；
- 与能力徽章和成长激励系统联动。

---

## 6. 学段教学适配器基础

同一套六步方法不能简单复制给一年级和六年级，因此 V3 引入“学段教学适配器”。

### 一至二年级

规划方向：

- 图片点选；
- 拖拽；
- 语音表达；
- 一屏一问；
- 短学习时长；
- 家长陪伴模式。

### 三至四年级

主要采用：

- 选择；
- 排序；
- 短文本表达；
- 图形操作；
- 逐步提示。

### 五至六年级

主要采用：

- 完整知识地图；
- 多步推理；
- 自我解释；
- 三阶挑战；
- 一题三变；
- 课堂重点总结。

Alpha 当前已经完成适配器数据结构和页面识别基础；低年级专属语音、拖拽等交互组件仍在后续开发范围内。

# 数据与隐私设计

V3.0 默认采用“本地优先”的设计思路。

- 默认使用孩子昵称，不要求真实姓名；
- 推荐使用 AI 人物形象，不要求上传真实照片；
- 课程包不包含孩子个人信息；
- 学习进度与课程包数据分离；
- 导出课程包时不导出孩子数据；
- 当前项目不包含原始教材 PDF；
- API Key 正式使用时应存放在本地服务端，而不是前端代码；
- AI 生成且尚未完成复核的教材内容必须明确提示家长检查。

# 当前版本边界

V3.0 Alpha **还没有**实现从前端上传教材 PDF 后自动生成整学期课程包。

这一能力属于下一阶段 V3.1。

当前版本重点是先把课程包体系、课程运行时、工作台解耦和首次创建体验做稳定。

# V3.1 规划：自定义教材生成

下一阶段计划把现有 `math-semester-preview` Skill 改造成可被工作台调用的 Headless 内容引擎。

目标流程：

```text
上传教材 PDF
→ 文件质量检查
→ OCR / 目录识别
→ 家长确认目录
→ 生成一个样板单元
→ 家长确认
→ 逐单元生成整学期内容
→ 数学 / 来源 / 完整度校验
→ 导出 Curriculum Package V3
→ 安装到学习基地
```

计划支持：

- PDF 上传；
- 本地 OCR；
- 教材目录解析；
- 家长编辑和确认目录；
- 样板单元；
- 单元级生成任务；
- 暂停 / 继续；
- 失败重试；
- 单元重新生成；
- 来源页码映射；
- 自动质量检查；
- 课程包安装。

# V3.2 规划：课程包社区

未来希望形成一个可共享、可维护的教材课程包生态：

- 课程包版本管理；
- 教材指纹；
- 官方维护 / 社区审核状态；
- 社区贡献课程包；
- 问题反馈；
- 内容修订；
- 多教材版本兼容。

普通家长优先一键安装已经审核的课程包；只有课程库没有对应教材时，才需要自己上传 PDF 生成。

# 项目愿景

我们希望这套项目最终不是一个固定的“五年级数学工作台”，而是一套真正可复用的家庭学习框架：

> **选择或上传孩子的教材，结合孩子的年级、兴趣和学习节奏，创建这个学期专属的学习冒险基地。**

如果你正在尝试 AI + 家庭教育、游戏化学习、教材预习、儿童 Agent 或课程包生成，欢迎一起参与这个项目。
