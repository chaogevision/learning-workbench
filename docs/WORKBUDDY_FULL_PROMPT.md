## 可直接复制的总提示词

```text
你现在是一个由高级产品经理、儿童教育产品设计师、UI/UX 设计师、SVG 插画师、前端工程师、Node.js 工程师和测试工程师组成的完整产品团队。

项目名称：孩子名字 + 学习冒险基地（动态显示）

一、项目目标

为小学阶段孩子和家长制作一套游戏化家庭学习工作台。核心不是拍照搜题或自动批改，而是：

1. 家长安排与追踪今日学习任务；
2. 孩子进入任务、保存进度并留下真实学习证据；
3. 孩子通过结构化预习单完成课前探索；
4. 完成任务后获得成长星、金币、经验与地图能量；
5. 学习区域被逐步点亮；
6. 家长从成长档案查看过程记录和复核内容。

核心闭环必须是：

安排任务 → 执行任务 → 留下学习证据 → 完成六步预习 → 课堂验证 → 获得成长反馈 → 点亮成长地图。

二、视觉参考

请优先读取并参考以下设计图：

- docs/prototypes/01-home.png

如果这些文件以聊天附件形式提供，也要以附件为视觉依据。

不是要求机械像素复制，而是必须保持以下视觉语言：

- 明亮、现代、儿童友好的教育产品；
- 白色与浅蓝背景；
- 蓝色主色，绿色、黄色、橙色、紫色作为学科和奖励辅助色；
- 大圆角卡片、轻阴影、柔和渐变；
- 信息层级清楚，不能把内容堆成密集表格；
- 具有游戏世界和学习冒险感，但不能幼稚到像低龄启蒙 App；
- 桌面端成品必须适合录屏演示，第一眼有完整产品感；
- 手机端必须可用。

三、不可违反的视觉约束

1. 禁止使用 Emoji 作为任何图标或插画。
2. 禁止使用系统 Emoji 字体、Emoji 字符、Icon Font 和远程图标 CDN。
3. 所有图标都必须制作成本地 SVG，放在 assets/icons/。
4. 所有吉祥物、头像和页面插画都必须是本地原创 SVG。
5. 不使用有版权风险的动画角色、游戏角色或品牌吉祥物。
6. 不下载或外链字体文件，使用系统中文字体。
7. 不使用图片里的文字代替真实 HTML 文本。
8. 图标和状态不能只靠颜色区分，必须同时有文字或形状。
9. active 导航不能通过滤镜把整个 SVG 变成纯白方块。
10. 品牌入口必须清除浏览器 button 默认边框和灰色背景。

四、专属吉祥物

必须设计一个原创专属吉祥物，默认名称“小探星”。

标准造型：

- 黄色到橙黄色的圆润豆形身体；
- 大眼睛、微笑、浅粉脸颊；
- 小探险帽，帽子有星形标志；
- 蓝色背包或蓝色耳侧装置；
- 胸口有星形标识；
- 短手短脚，动作亲切；
- 扁平矢量风，柔和渐变，清晰深蓝描边。

至少制作 3 个 SVG 姿态：

- 挥手或举旗：用于首页和今日任务；
- 拿地图：用于成长地图；
- 拿清单：用于成长档案。

预习页可以复用挥手姿态，也可以增加拿放大镜的姿态。

吉祥物必须拥有独立区域，而不是只放一个小头像。每个核心页面都要显示：

- “我的专属吉祥物”或对应页面标题；
- 吉祥物插画；
- 一句和当前页面动作有关的鼓励；
- 用户自定义吉祥物名字；
- 设置入口。

用户可修改孩子昵称、年级、每日可用时间和吉祥物名字。修改后所有页面同步更新。

七、首页详细要求

左侧：

1. 儿童档案卡
   - 默认昵称：小明；
   - 默认年级：四年级；
   - Lv.5 小小探索家；
   - 经验值 680/1000；

主区域上部：

- 标题“今日冒险总览”；
- 3 张任务卡：数学、英语、语文阅读；
- 每张显示学科、任务名、主题插画、预计时间、成长星、金币、状态按钮；

八、今日任务页详细要求

桌面端三栏：左侧儿童与吉祥物，中间任务主区，右侧工具区。

顶部总览：

- 今日目标数量；
- 计划用时；
- 已完成数量；
- 今日连击；
- 添加任务按钮。

任务分组：

- 必做任务 required；
- 选做挑战 optional；
- 冒险任务 adventure。

支持按学科筛选。

任务卡字段：

- subject；
- icon；
- group；
- title；
- description；
- minutes；
- difficulty 1—3；
- focus；
- reward.stars；
- reward.coins；
- reward.xp；
- reward.mapEnergy；
- status：todo、in_progress、done；
- progress 0—100；
- evidence。

任务详情必须真实可操作：

- 查看说明；
- 调整进度；
- 输入学习证据；
- 保存进度；
- 完成并领取奖励；
- 删除任务。

重要规则：没有填写学习证据，不能完成任务。已经完成的任务不能重复领取奖励。

右侧工具区：

1. AI一键安排任务
   - 年级；
   - 可用时间；
   - 今日重点，多选；
   - 智能生成任务。

2. 15分钟专注挑战
   - 开始；
   - 暂停；
   - 重置；
   - 页面刷新后恢复计时；
   - 完成后奖励；
   - 中断不扣分。

3. 闯关规则
   - 第1关、第2关、第3关；
   - 集满成长星开启宝箱。

中部下方展示轻量追踪：

- 本周任务柱状图；
- 今日时间分配环图；
- 学科投入雷达图。

不要把这些图表表述为专业学情诊断。

九、预习单页详细要求

这是产品差异化重点，不能只做一个普通表单。

页面顶部：

- 标题“预习单”；
- 当前课题；
- 预计用时；
- “AI生成预习单”按钮；
- 家长模式切换。

课程目标区：

- 本课目标；
- 教材页码或“待家长核对”；
- 来源说明；
- 完成进度。

知识卡：默认 3 张，可支持 5 张。每张必须包含：

- 标题；
- 核心知识；
- 关键词；
- 易错点；
- 预习问题。

固定六步预习流程，顺序和 id 不能改变：

1. id=overview，标题=看全貌，副标题=我已经知道什么，icon=book；
2. id=baseline，标题=测基础，副标题=快速试一试，icon=clipboard；
3. id=understand，标题=想明白，副标题=本课我先观察，icon=thinking；
4. id=verify，标题=验理解，副标题=用自己的话说，icon=reading；
5. id=transfer，标题=练迁移，副标题=动手试一试，icon=science；
6. id=focus，标题=定重点，副标题=我的问题与课堂验证，icon=preview。

每一步必须包含：

- 步骤数字；
- 标题与副标题；
- 明确动作说明；
- 输入区域；
- 奖励；
- 完成按钮；
- 完成状态。

没有输入真实记录时不能完成。完成后保存到 localStorage，并且不能重复发奖励。

预习成果记录区：

- 知识卡片；
- 我的问题；
- 我的实验；
- 我的猜想；
- 导出记录。

三阶挑战：

1. 认一认：3选1；
2. 说一说：自由输入，要求孩子用自己的话解释；
3. 用一用：生活迁移或简单应用。

生成交通灯反馈：

- 绿灯：三项达到基础要求；
- 黄灯：完成两项；
- 红灯：需要返回知识卡继续观察。

反馈不能写成考试分数，也不能羞辱孩子。

家长模式显示：

- 来源说明；
- 人工复核提醒；
- 家长已复核勾选；
- 家长备注；
- 导出预习 JSON。

禁止：

- 反复点击完成刷奖励；

- 连续学习中断后扣星；

十五、API 接口

首版只预留两个轻量接口：

POST /api/ai/generate-tasks
POST /api/ai/generate-preview

不要接 OCR、自动批改和错题诊断。

前端必须有：

assets/js/config.js

默认采用自动模式：

apiMode: window.location.protocol === 'file:' ? 'mock' : 'proxy'

即：直接双击文件时离线运行；通过本地 Node 服务或正式域名打开时请求同源代理。允许保留手动覆盖配置，但正常使用不要求家长修改代码。

当 proxy 请求失败时，前端自动回退到本地模板，并用 Toast 说明，不得让页面失效。

服务端使用 Node.js 18+，只使用内置模块，不强制安装第三方依赖。

服务端必须：

- 同时提供静态页面；
- 读取 .env；
- 只在服务端保存 API Key；
- 支持 API_MODE=mock；
- 支持 API_MODE=compatible；
- 兼容 Chat Completions 风格接口；
- 限制请求体；
- 做基础限流；
- 对模型输出做白名单和数值校验；
- 提供 GET /api/health。

环境变量模板：

HOST=127.0.0.1
PORT=4173
API_MODE=mock
AI_API_BASE_URL=https://your-provider.example/v1
AI_API_PATH=/chat/completions
AI_API_KEY=replace_with_server_side_key
AI_MODEL=replace_with_lightweight_model
AI_JSON_MODE=auto
AI_TIMEOUT_MS=40000

严禁把密钥写入前端。

二十、响应式与无障碍

- 大于 1220px：完整桌面布局；
- 931—1220px：任务右栏移至主栏下；
- 小于 930px：底部导航、单列内容；
- 小于 640px：预习步骤、知识卡、徽章全部单列；
- 390px 宽不能横向溢出；
- 所有输入有 label；
- 所有只有图标的按钮有 aria-label；
- focus-visible 清楚；
- 按钮点击区域至少约 42×42；
- 不只用颜色表达完成与锁定。
```
