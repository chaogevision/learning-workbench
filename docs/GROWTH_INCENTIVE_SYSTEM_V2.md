# 成长激励系统 V2｜设计与实现说明

## 1. 核心目标

V2 不再把徽章当作零散奖励，也不再让多个积分资源互相重叠。

系统主链路：

```text
真实学习行为
  → 经验值与探索币
  → 有效学习证据产生成长星
  → 推动具体能力徽章
  → 解锁成长地图与长期里程碑
```

## 2. 三个核心资源

### 经验值 XP
- 只累计，不消费；
- 决定孩子等级和称号；
- 普通任务、专注挑战、预习步骤都会产生经验。

### 成长星
- 代表有学习证据的有效成果；
- 永久累计，不用于消费；
- 用于地图解锁、里程碑和长期统计；
- 只有提交解释、问题、作品或完整预习等证据时才产生。

### 探索币
- 可消费资源；
- 用于兑换伙伴配件、地图主题和家庭自定义奖励；
- 工作台内提供轻量奖励商店。

## 3. 七大能力分类

1. 学习习惯
2. 思考能力
3. 表达沟通
4. 学科学习
5. 自主学习
6. 创造项目
7. 里程碑

首发共 26 枚徽章。

## 4. 徽章阶段

- 未点亮
- 萌芽
- 成长
- 闪耀

每枚徽章拥有独立证据计数和三个阶段阈值。

## 5. 证据来源

- 任务完成证据
- 解释与复述质量
- 连续学习记录
- 专注挑战
- 六步预习完整度
- 三阶挑战与一题三变
- 区域学科任务
- 项目作品

## 6. 页面联动

### 首页
展示离升级最近的 3 项“今日可点亮能力”。

### 今日任务
任务卡显示 XP、探索币、成长星以及主要培养能力。

### 预习单
完整六步预习后一次性推动：预习探险家、提问小侦探、思路小工程师、规律发现家和数学思考家。

### 成长地图
区域解锁同时检查成长星和对应能力条件。

### 成长档案
提供：能力总览、今日可点亮能力、分类徽章墙、最近点亮、区域成就和奖励流水。

## 7. 防刷与安全

- 任务奖励使用唯一 claimId，避免重复领取；
- 专注挑战每日最多发放 4 次数值奖励；
- 成长星只在提交真实证据或完整流程后发放；
- API Key 仍建议放在服务端代理，不建议浏览器长期保存。

## 8. 旧数据迁移

应用状态版本升级为 3。加载旧 V1.6/V1.5 数据时会自动：

- 星星 → 成长星；
- 金币 → 探索币；
- 旧徽章映射到对应能力进度；
- 旧任务奖励转换为 V2 奖励结构；
- 保留孩子档案、头像、任务、预习和学习日历。
