# AI学习冒险基地｜完整开发说明文档

版本：1.0  
目标用户：小学阶段孩子及其家庭  
主要使用场景：家庭学习任务安排、执行追踪、课前预习、成长反馈  
交付形态：可离线运行的单页网页应用；可选同源轻量 API

---

## 1. 产品定义

### 1.1 一句话定位

一套让家长能够安排和追踪学习任务、让孩子愿意主动进入并留下学习证据的游戏化家庭学习工作台。

### 1.2 核心问题

小学家庭辅导中最稳定、最高频的需求不是“再增加一个讲题入口”，而是：

- 今天究竟做什么；
- 每项任务要做到什么程度；
- 孩子是否真正完成，而不是只点了按钮；
- 预习应该怎样做，才能带着问题进入课堂；
- 家长怎样看到一段时间内的进步，而不只盯着分数；
- 学习过程如何获得正反馈，又不制造排名压力。

### 1.3 核心闭环

```text
创建儿童档案
→ 安排今日任务
→ 进入任务并记录完成证据
→ 获得成长星、金币、经验和地图能量
→ 完成六步课前预习
→ 通过认一认、说一说、用一用形成初步反馈
→ 点亮成长地图
→ 在成长档案中查看记录与家长建议
```

### 1.4 非目标

首版明确不做：

- 自动拍照搜题；
- 作业自动批改；
- 自动错题诊断；
- 复杂课程商城；
- 班级与公开排行榜；
- 社交动态与公开作品广场；
- 需要数据库才能成立的账号体系。

## 2. 教育与产品原则

### 2.1 工作台管理学习流程，不替孩子学习

AI 可生成任务结构和预习初稿，但孩子必须完成观察、表达、解释、尝试和验证。

### 2.2 任务完成必须有证据

至少保留一种可检查的结果：

- 一句总结；
- 一段解释；
- 一个问题；
- 一张图或作品；
- 一项观察记录；
- 一道题的思路说明。

页面不把“点击完成”直接等价为掌握。

### 2.3 预习不是提前学完整节课

预习页固定围绕：

```text
看全貌 → 测基础 → 想明白 → 验理解 → 练迁移 → 定重点
```

孩子最终应带着一个问题和一个猜想进入课堂，而不是提前背完答案。

### 2.4 奖励成长，不制造比较

允许：

- 地图点亮；
- 成长星；
- 能力徽章；
- 宝箱；
- 吉祥物反馈；
- 身份等级；
- 连续学习记录。

禁止：

- 公开排名；
- 比速度；
- 连续学习中断后扣分；
- 羞辱性反馈；
- 用奖励诱导无意义刷任务。

### 2.5 家长是管理者，孩子是行动者

家长主要负责：

- 设置昵称、年级和时间；
- 添加或生成任务；
- 核对预习内容；
- 查看成长档案；
- 帮助低龄孩子操作。

孩子主要负责：

- 选择和执行任务；
- 留下学习证据；
- 完成预习步骤；
- 用自己的话解释；
- 提出问题和猜想。

## 3. 信息架构

### 3.1 顶部主导航

固定五个入口：

1. 首页
2. 今日任务
3. AI预习单
4. 成长地图
5. 成长档案

顶部右侧固定显示：

- 宝石数量；
- 金币数量；

本项目采用 Hash Route，避免静态部署时刷新 404：

```text
#/home
#/tasks
#/preview
#/map
#/archive
```

### 3.3 页面布局

桌面端：

- 顶部：76 px 固定导航；
- 页面最大宽度：1540 px；
- 左侧固定信息栏：儿童档案、吉祥物和收藏；
- 中间：核心任务内容；
- 任务页额外增加右侧工具栏；
- 卡片间距：16—18 px。

移动端：

- 顶部只保留品牌与头像；
- 主导航下沉为底部悬浮栏；
- 所有三栏和双栏布局转为单列；
- 任务卡与地图节点保持大点击区域。

## 6. 页面一：首页

### 6.1 页面目标

让孩子打开后在 5 秒内知道：

- 今天要做什么；
- 先从哪一项开始；
- 完成后会获得什么；
- 自己正在成长到哪里。

### 6.2 桌面结构

```text
左侧栏
├── 儿童档案
└── 专属吉祥物

主区域上半部
├── 今日冒险总览：3 张任务卡
└── AI 帮我安排今天任务

主区域中部
├── 本周任务追踪
├── AI预习单快捷入口
└── 成长地图预览

主区域底部
└── 奖励、徽章、宝箱和今日小目标
```

### 6.3 今日任务卡

每张卡包含：

- 学科；
- 任务名称；
- 主题插画；
- 预计时间；
- 成长星；
- 金币；
- 当前状态；
- 进入按钮。

### 6.4 AI 生成任务入口

生成器字段：

- 年级；
- 可用时间；
- 今日重点，多选；
- 家长补充目标。

### 6.5 首页验收

- 三个任务卡完整显示；
- 可点击进入任务或预习页；
- 吉祥物区域足够醒目；
- 地图缩略图与完整地图视觉一致；

## 7. 页面二：今日任务

### 7.1 页面目标

从“任务清单”升级成“安排—执行—留证—追踪”的家庭学习工作流。

### 7.2 左侧栏

- 儿童档案；
- 专属吉祥物；
- 今日连击；
- 徽章碎片与收藏。

### 7.3 顶部总览

展示：

- 今日目标数量；
- 计划用时；
- 已完成数量；
- 今日连击；
- 增加任务按钮。

### 7.4 任务分组

固定三组：

- `required`：必做任务；
- `optional`：选做挑战；
- `adventure`：冒险任务。

任务状态：

- `todo`：未开始；
- `in_progress`：进行中；
- `done`：已完成。

### 7.5 任务卡字段

```text
id
subject
icon
group
title
description
minutes
difficulty
focus
reward.stars
reward.coins
reward.xp
reward.mapEnergy
status
progress
evidence
```

### 7.6 任务详情

任务详情弹窗包含：

- 学科和训练重点；
- 任务说明；
- 时间和奖励；
- 0—100% 进度；
- 学习证据输入框；
- 保存进度；
- 完成并领取奖励；
- 删除任务。

完成门槛：学习证据至少 2 个有效字符。生产版可提高为 8—20 字，或支持上传图片。

### 7.7 AI 一键安排任务

右侧工具卡字段：

- 年级；
- 可用时间；
- 今日重点；
- 生成按钮。

接口失败时必须自动使用本地模板，页面不出现不可恢复错误。

### 7.8 专注挑战

首版为 15 分钟倒计时：

- 开始、暂停、重置；
- 本地保存最后时间戳；
- 页面刷新后恢复剩余时间；
- 完成后奖励成长星、金币和经验；
- 不因中途退出扣分。

### 7.9 任务分析

仅显示轻量追踪，不宣称“AI 学情诊断”：

- 本周完成数量；
- 今日时间分配；
- 学科投入雷达图。

这些数据用于家庭规划，不作为能力测评结论。

## 8. 页面三：AI预习单

### 8.1 页面目标

把课前预习设计为一段可执行的探究路径，而不是一张需要孩子机械填写的电子表格。

### 8.2 页头

包含：

- 页面标题；
- 当前课题；
- 预计用时；
- AI 生成预习单按钮。

### 8.3 课程目标

显示：

- 本课目标；
- 教材页码或“待家长核对”；
- 内容来源说明；
- 当前完成进度；
- 家长模式切换。

### 8.4 知识卡

默认 3 张，可扩展至 5 张。

每张包含：

- 标题；
- 核心知识；
- 关键词；
- 易错点；
- 一个预习问题。

知识卡只帮助孩子识别本课全貌，不应把整节课讲透。

### 8.5 六步预习流程

#### 第一步：看全貌

- 激活已有经验；
- 让孩子写下“我已经知道什么”。

#### 第二步：测基础

- 快速判断已有起点；
- 记录最确定和最不确定的内容。

#### 第三步：想明白

- 观察教材图示、例子或关键词；
- 写下一条真实发现。

#### 第四步：验理解

- 用自己的话解释；
- 禁止只照抄课本原句。

#### 第五步：练迁移

- 画一画、摆一摆、测一测、读一读或完成一道简单迁移；
- 记录过程或结果。

#### 第六步：定重点

- 写下最想带进课堂的问题；
- 写下当前猜想；
- 明确课堂验证方向。

### 8.6 三阶挑战

#### 认一认

- 单选；
- 检查最基础的概念识别；
- 不追求题量。

#### 说一说

- 自由表达；
- 检查孩子是否能脱离教材解释。

#### 用一用

- 生活迁移或简单应用；
- 检查初步理解能否迁移。

### 8.7 交通灯反馈

- 绿灯：三项均达到基础要求；
- 黄灯：完成两项，仍有一个点值得课堂验证；
- 红灯：需要先回到知识卡或预习步骤继续观察。

交通灯只表示当前预习状态，不等同于考试评价。

### 8.8 家长复核

家长模式显示：

- 来源说明；
- 教材核对提醒；
- 家长复核勾选；
- 家长备注；
- 导出预习记录。

### 8.9 AI 生成预习单

输入：

- 年级；
- 学科；
- 教材版本；
- 课题；
- 教材内容或本课要点。

输出：

- 课程基本信息；
- 3—5 张知识卡；
- 固定六步路径；
- 三阶挑战；
- 来源与人工复核说明。

接口不可用时使用通用模板，不能让整个预习页失效。

## 9. 页面四：成长地图

### 9.1 页面目标

让任务记录和预习行为形成看得见的长期进度，而不是仅显示数字和表格。

### 9.2 地图区域

首版六个区域：

- 知识森林：语文；
- 数学峰谷：数学；
- 英语海湾：英语；
- 科学火山：科学；
- 阅读城堡：阅读；
- 编程迷宫：锁定区域。

### 9.3 区域状态

- 已完成；
- 已解锁并进行中；
- 未解锁。

状态必须同时使用：

- 颜色；
- 图标；
- 百分比；
- 文字或锁标识。

### 9.4 地图数据

```text
id
name
subject
icon
progress
stars
unlocked
unlockAt
x
y
color
description
```

### 9.5 解锁逻辑

- 完成任务获得成长星和地图能量；
- 累计成长星达到阈值后解锁区域；
- 解锁只增加，不回退；
- 中断学习不会让区域重新上锁。

### 9.6 地图交互

点击区域弹出：

- 区域名称；
- 学科；
- 当前进度；
- 星级；
- 是否解锁；
- 下一步建议或解锁条件。

## 10. 页面五：成长档案

### 10.1 页面目标

为家长提供轻量但可信的过程记录，不伪装成专业学情诊断报告。

### 10.2 本周成长报告

展示：

- 一句本周亮点；
- 完成任务数；
- 成长星；
- 连续学习；
- 本周完成比例。

### 10.3 学习记录

记录类型：

- 任务；
- 预习；
- 徽章；
- 专注挑战。

### 10.4 能力徽章

徽章奖励行为，不评价孩子和别人谁更强。

示例：

- 坚持学习；
- 时间管理达人；
- 口语小能手；
- 阅读之星；
- 提问小达人。

### 10.5 家长工具

- 切换家长模式；
- 导出本地数据；
- 重置演示数据；
- 查看陪伴原则与复核提醒。

## 11. 游戏化系统

### 11.1 资源类型

#### 成长星

用于：

- 地图进度；
- 区域解锁；
- 宝箱进度。

#### 金币

首版只展示积累，可用于后续兑换吉祥物帽子、背包与地图皮肤。

#### 经验值

用于角色等级提升。

#### 宝石

高阶资源预留，首版不与付费绑定。

#### 徽章碎片

用于合成能力徽章。

#### 地图钥匙

区域解锁反馈。

### 11.2 奖励触发

- 任务真实完成；
- 完成一项预习步骤；
- 完成 15 分钟专注挑战；
- 达成阶段性行为目标。

### 11.3 不允许触发奖励的行为

- 只打开页面；
- 只播放内容；
- 反复点击同一个完成按钮；
- 未留下任何完成证据。

### 11.4 防重复

- 任务状态变为 `done` 后不重复发放；
- 预习步骤 `complete=true` 后不重复发放；
- 专注挑战完成后重置下一轮；
- 所有奖励操作先检查状态再写入。

### 12.1 本地存储

ai-learning-adventure-base-v1

保存内容：

- 品牌只显示图形；
- 预习步骤、知识卡、徽章全部单列；
- 地图节点重新排列；

## 16. 技术实现

### 16.1 前端

- 原生 HTML、CSS、JavaScript；
- 无构建步骤；
- 无 CDN；
- 无第三方框架依赖；

### 16.3 文件职责

- `assets/js/app.js`：页面渲染、状态更新与交互；
- `server.mjs`：静态服务器与模型代理；

## 17. 安全要求

- API Key 只存在 `.env`；
- 浏览器网络请求只能访问自己的代理；
- 限制请求体大小；
- 对外部模型结果做字段白名单与数值边界校验；
- 所有用户文本进入 HTML 前转义；
- 不允许模型返回任意 HTML 并插入页面；
- 不允许模型控制文件路径、命令或系统提示；
- 生产部署需要 HTTPS、反向代理、访问日志脱敏和密钥轮换；
- 发送给模型的儿童信息只保留昵称、年级和任务目标。
