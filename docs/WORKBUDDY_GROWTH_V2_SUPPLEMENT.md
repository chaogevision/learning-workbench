# WorkBuddy 增补提示词｜成长激励系统 V2

请在“孩子学习冒险基地”中采用以下统一成长机制，不得继续保留互相重叠的旧积分逻辑。

## 1. 核心资源

只保留三个核心成长资源：

1. **经验值 XP**：只累计，用于等级与称号。
2. **成长星**：由有效学习证据产生，只累计，用于地图与里程碑解锁。
3. **探索币**：可消费，用于伙伴配件、主题皮肤、地图装饰与家庭奖励。

不要再把宝石作为主资源；不要使用统一徽章碎片兑换能力徽章。

## 2. 能力徽章

采用七大分类：

- 学习习惯
- 思考能力
- 表达沟通
- 学科学习
- 自主学习
- 创造项目
- 里程碑

每枚徽章拥有：

- 独立 evidence progress
- 萌芽阈值
- 成长阈值
- 闪耀阈值
- 关联任务行为
- 可选关联地图区域

## 3. 奖励规则

普通任务完成后：

- 发放 XP 与探索币；
- 只有提交有效学习证据时才发放成长星；
- 推动任务关联的一个或多个能力徽章；
- 通过唯一 `claimId` 防止重复领奖。

完整六步预习后：

- 发放完整预习奖励；
- 推动预习探险家、提问小侦探、思路小工程师、规律发现家和对应学科徽章；
- 在完成页展示“本次推动了哪些能力”。

## 4. 页面要求

### 首页
展示“今日可点亮能力”，选择距离下一阶段最近的三枚徽章。

### 今日任务
每张任务卡显示：

- XP
- 探索币
- 成长星条件
- 主要培养能力

### 成长地图
区域解锁同时检查：

- 成长星阈值
- 指定能力徽章阶段

### 成长档案
重构为：

- 能力总览
- 今日可点亮能力
- 分类徽章墙
- 最近点亮时间线
- 区域成就
- 奖励流水
- 家长中心

## 5. 数据迁移

加载旧数据时自动迁移：

- stars → growthStars
- coins → exploreCoins
- old badges → badge evidence progress
- old task rewards → V2 reward schema

不要清空孩子已经积累的任务、头像、预习进度和学习日历。
