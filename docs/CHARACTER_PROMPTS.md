# 角色与吉祥物提示词模板

本项目新增了两套示例角色资产：

1. **小明**（小学阶段小朋友专属学习形象）
2. **探索龙 Dino**（原创学习吉祥物）

> 说明：为了演示和页面落地，本次采用“六宫格角色表”方式生成，再切分为单张 PNG 资产。

---

## 一、小朋友角色提示词模板

### 基础版（单张）

创建一张适合儿童教育产品网页使用的原创卡通角色形象图。角色是一位中国小学生男孩，约 9-10 岁，黑色短发，大眼睛，微笑，脸型偏可爱、下巴略尖，穿蓝色探索风连帽卫衣、深色短裤、运动鞋、黄色小背包，胸前有星星徽章。整体风格为高品质 3D / 卡通教育产品风格，干净背景，适合网页 UI 使用。

### 六姿态版（推荐）

创建一张儿童教育网页的角色 sprite sheet。展示同一个原创卡通男孩“小明”的 6 个全身姿态，3 列 x 2 行排布，浅色纯净背景，角色之间留足裁切空间。角色设定保持一致：10 岁左右中国小学生，黑色短发，大眼睛，微笑，略尖下巴，蓝色探索风连帽卫衣，深色短裤，运动鞋，黄色小背包，星星徽章。风格为精致可爱 3D / 卡通教育产品风格。六个姿态分别为：1）欢迎挥手；2）坐在书桌前学习 / 写字；3）思考姿态；4）拿放大镜和教材进行探索；5）举起星星奖章庆祝；6）手持地图或望远镜探险。不要文字，不要 emoji，每个姿态适合单独裁切成网页素材。

## 二、吉祥物提示词模板

### 基础版（单张）

创建一张适合儿童教育产品网页使用的原创学习吉祥物图像。吉祥物名为“探索龙 Dino”，是一只圆润可爱的原创小恐龙，不参考任何已有版权角色。它有蓝绿色身体、浅黄色肚皮、大眼睛、粉色脸颊、小尾巴，戴探险帽和小背包，帽子上有星星徽章。整体风格是高品质 3D / 卡通教育产品风格，干净背景，适合网页 UI 使用。

### 六姿态版（推荐）

创建一张儿童教育网页的吉祥物 sprite sheet。展示同一个原创学习吉祥物“探索龙 Dino”的 6 个全身姿态，3 列 x 2 行排布，浅色纯净背景，角色之间留足裁切空间。吉祥物必须原创，不参考任何已有版权角色。设定为圆润可爱的宝宝恐龙：蓝绿色身体、浅黄色肚皮、大眼睛、粉色脸颊、小尾巴、小探险帽、星星徽章和小背包。风格为精致可爱 3D / 卡通教育产品风格。六个姿态分别为：1）默认陪伴；2）手持任务卡引导；3）鼓励点赞；4）托腮思考；5）庆祝获得奖励；6）抱书休息。不要文字，不要 emoji，每个姿态适合单独裁切成网页素材。
