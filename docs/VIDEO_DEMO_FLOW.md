# 成品视频演示建议｜约 70—100 秒

## 1. 结果前置：10—15 秒

连续展示：首页专属吉祥物、今日任务、六步预习单、成长地图。

推荐口播：

> 最近很多人用 Agent 做自己的工作台。我给小学阶段的孩子做了一个家庭学习冒险基地：每天学什么、做到哪里、预习留下了什么问题，全部放在一个专属页面里。

## 2. 今日任务闭环：20—25 秒

1. 点击“一键生成任务”；
2. 选择四年级、60 或 90 分钟、数学和英语；
3. 展示新任务出现；
4. 打开任务，填写一句学习证据；
5. 完成任务，成长星和地图进度增加。

演示重点：不是点击打卡，而是必须留下真实学习记录。

## 3. AI预习单：25—35 秒

1. 展示知识卡；
2. 快速扫过六步：看全貌、测基础、想明白、验理解、练迁移、定重点；
3. 填写一个“我已经知道什么”；
4. 展示“认一认、说一说、用一用”；
5. 生成交通灯反馈。

演示重点：预习不是提前把答案学完，而是激活旧知、提出问题并准备课堂验证。

## 4. 游戏化成长：15—20 秒

1. 打开成长地图；
2. 点击知识森林或数学峰谷；
3. 展示星级、区域进度和下一步建议；
4. 回到专属吉祥物区域。

演示重点：奖励用来显示成长和推进路线，不做排行榜，不因中断扣分。

## 5. 制作过程：10—15 秒

只保留 3 个镜头：

1. 把完整需求发给 WorkBuddy；
2. WorkBuddy 创建页面、SVG 和代码文件；
3. 继续一句话修改视觉或 API 配置。

结尾提示：完整手把手搭建可作为下一期内容；本期重点让观众先看到成品价值。
