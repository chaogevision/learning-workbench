# AI学习冒险基地｜图标、插画与专属吉祥物规范

## 1. 总原则

1. 全部使用本地 SVG。
2. 不使用 Emoji、Emoji 字体、Icon Font 或远程图标 CDN。
3. 图标必须服务于识别和状态，不作为纯装饰堆叠。
4. 相同语义只使用一个图标，不随页面任意更换。
5. 图标文件使用英文小写和连字符命名。
6. 功能图标统一 `viewBox="0 0 64 64"`。
7. 图标线条主色统一为深蓝 `#17345f`，推荐描边 2.5—3.5 px。
8. 每个图标最多使用 1 个主强调色和 1 个辅助色。
9. 图标中的文字仅限必要的短字符，例如数学符号和 `EN`。
10. 状态不能只靠颜色，必须配合图标或文字。

## 2. 视觉语言

### 2.1 功能图标

- 外层可使用 56×56 的圆角方形底板；
- 底板从淡蓝或淡紫渐变到白色；
- 主体为深蓝描边和白色填充；
- 局部使用蓝、绿、黄、橙或紫；
- 允许极轻的 SVG 阴影；
- 不使用写实材质和复杂光影。

### 2.2 导航图标

- 在 22—25 px 显示时仍能辨认；
- 选中状态不把整个 SVG 强制变白；
- 依靠导航胶囊背景和文字颜色表达选中；
- 图标本身保持原有配色，避免变成白色方块。

### 2.3 任务学科图标

推荐语义色：

- 数学：蓝色；
- 英语：绿色；
- 语文与阅读：紫色；
- 科学：橙红；
- 思维：紫蓝；
- 预习：橙色。

## 5. 专属吉祥物：小探星

### 5.1 角色定位

小探星不是系统 Logo，也不是老师。它是孩子的专属学习伙伴和地图向导。

角色作用：

- 提醒下一步；
- 提供鼓励；
- 解释奖励；
- 引导孩子留下学习证据；
- 在预习时提醒“带着问题进课堂”。

### 5.2 标准造型

- 身体：圆润的黄色到橙黄色豆形；
- 眼睛：大而清晰，保持友善；
- 面部：微笑、浅粉脸颊；
- 标志：额头或帽子上的五角星；
- 配件：探险帽、蓝色耳侧装置或背包；
- 胸口：星形标识；
- 四肢：短而有动作感；
- 风格：原创、扁平矢量、柔和渐变、清晰描边。

### 5.3 当前姿态

| 文件 | 姿态 | 页面用途 |
|---|---|---|
| `xiaotanxing-wave.svg` | 挥手/举旗 | 首页与任务页 |
| `xiaotanxing-map.svg` | 拿地图 | 成长地图 |
| `xiaotanxing-clipboard.svg` | 拿清单 | 成长档案 |

预习页可复用挥手姿态，也可后续新增：

- `xiaotanxing-magnifier.svg`：拿放大镜；
- `xiaotanxing-question.svg`：举问题卡；
- `xiaotanxing-experiment.svg`：拿量角器或实验工具。

### 5.4 专属化字段

用户可以修改：

- 吉祥物名字；
- 未来扩展中的帽子、背包、胸章和地图皮肤。

用户不能在首版修改：

- 基础脸型；
- 主体颜色；
- 角色核心辨识特征。

这样可以兼顾专属感和品牌一致性。

### 5.5 页面文案规则

吉祥物提示最好满足：

- 15—45 个汉字；
- 一次只推进一个动作；
- 不给完整答案；
- 不责备；
- 不用夸张焦虑词；
- 对孩子刚刚完成的真实行为作反馈。

示例：

- “先选最容易的一项开始，完成后再决定下一步。”
- “预习不是把答案全学会，而是找到一个值得带进课堂的问题。”
- “你已经留下了学习记录，这颗成长星是为真实思考获得的。”

## 8. 新增图标的制作模板

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64" role="img" aria-labelledby="title">
  <title>semantic-name</title>
  <defs>
    <linearGradient id="bg" x1="0" y1="0" x2="1" y2="1">
      <stop stop-color="#edf5ff"/>
      <stop offset="1" stop-color="#ffffff"/>
    </linearGradient>
  </defs>
  <rect x="4" y="4" width="56" height="56" rx="16" fill="url(#bg)"/>
  <!-- 使用深蓝描边和一个主强调色绘制主体 -->
</svg>
```

注意：同一 HTML 页面加载多个独立 SVG 文件时可以重复使用局部 `id`；若改为内联合并，则必须为渐变和滤镜 ID 加前缀，防止冲突。
