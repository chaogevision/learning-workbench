## 6. 未使用真实密钥测试的项目

项目已经实现 OpenAI-compatible Chat Completions 适配器、服务端密钥隔离、模型 JSON 结构校验、超时和失败回退。由于交付环境没有用户的真实模型供应商密钥，本次没有向外部模型供应商发起真实请求。

启用真实接口后，建议使用 `docs/API_INTEGRATION.md` 中的验证步骤，重点抽查：

1. 模型是否严格返回 JSON；
2. 任务总时间和任务数量是否符合约束；
3. 预习单是否固定返回六步；
4. 教材页码、定义、公式、图示和答案是否经过家长或教师复核；
5. API 超时、限流或结构异常时是否正确回退到本地模板。
