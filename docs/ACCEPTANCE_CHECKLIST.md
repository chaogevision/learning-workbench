# 孩子学习冒险基地｜交付验收清单

> 本文件既可作为交付核对模板，也可用于 WorkBuddy 二次生成后的复验。当前成品的实际执行结果见 `reports/FINAL_VALIDATION.md`；自动化结果见 `reports/api-smoke.json` 与 `reports/browser-smoke.json`。真实第三方模型的 Compatible 模式因未配置用户密钥，仅完成接口契约与回退逻辑验证，未绑定具体供应商。

## A. 文件与启动

- [ ] `index.html` 可直接打开。
- [ ] `START_HERE.html` 可跳转到首页。
- [ ] `node server.mjs` 可启动本地服务。
- [ ] Node.js 运行不需要安装第三方依赖。
- [ ] `GET /api/health` 返回正常 JSON。
- [ ] 所有静态资源使用相对路径。
- [ ] 无外部字体、图标或 CDN 依赖。
- [ ] README 包含离线、Mock 和 API 三种运行方式。

## B. 视觉一致性

- [ ] 五个页面使用同一顶部导航和色彩系统。
- [ ] 页面卡片圆角、边框和阴影一致。
- [ ] 首页呈现儿童档案、今日任务、AI任务入口、预习入口、地图预览和奖励。
- [ ] 今日任务页具有左栏、主任务区和右侧工具区。
- [ ] 预习页具有知识卡、六步流程和三阶挑战。
- [ ] 成长地图是页面主体，而不是普通数据表。
- [ ] 成长档案包含周报、记录、徽章和家长工具。
- [ ] 视觉中不出现 Emoji 图标。
- [ ] 所有功能图标来自 `assets/icons/*.svg`。
- [ ] 吉祥物为原创本地 SVG。
- [ ] 吉祥物区域在首页、任务、预习、地图和档案页可见。
- [ ] active 导航图标不会被滤镜变成纯白方块。
- [ ] 品牌按钮没有浏览器默认灰色边框。

## C. 导航与基础交互

- [ ] 五个主导航都能切换。
- [ ] 页面刷新后仍停留在对应 Hash 路由。
- [ ] 顶部头像可打开儿童档案设置。
- [ ] 可修改孩子昵称、年级、每日时间和吉祥物名称。
- [ ] 修改后所有页面同步显示。
- [ ] 消息按钮有友好演示提示。
- [ ] Toast 可正常出现并自动消失。
- [ ] 模态框可以关闭。
- [ ] 键盘焦点清晰可见。

## D. 今日任务

- [ ] 必做、选做、冒险三组筛选有效。
- [ ] 学科筛选有效。
- [ ] 可手动添加任务。
- [ ] AI任务生成器可打开。
- [ ] Mock 模式可生成 3—5 个任务。
- [ ] 新任务写入列表。
- [ ] 任务详情显示时间、奖励和训练重点。
- [ ] 任务进度可保存。
- [ ] 完成任务前必须填写学习证据。
- [ ] 完成后任务状态为 `done`。
- [ ] 同一任务不能重复领取奖励。
- [ ] 删除任务有效。
- [ ] 15 分钟专注计时可以开始、暂停和重置。
- [ ] 刷新后计时状态能够恢复。
- [ ] 专注完成后只发放一次奖励。

## E. 预习单

- [ ] 默认课题可展示。
- [ ] 3 张知识卡显示完整。
- [ ] 六步顺序为看全貌、测基础、想明白、验理解、练迁移、定重点。
- [ ] 每步都有输入区域和奖励说明。
- [ ] 没有输入时不能直接完成步骤。
- [ ] 完成步骤后状态保存。
- [ ] 已完成步骤不重复奖励。
- [ ] 认一认支持单选。
- [ ] 说一说和用一用支持自由输入。
- [ ] 可生成红、黄、绿三种预习反馈。
- [ ] 家长模式可切换。
- [ ] 家长可填写复核备注。
- [ ] 预习记录可以导出 JSON。
- [ ] 预习单生成器可用。
- [ ] API 失败后自动回退到六步本地模板。

## F. 成长地图与奖励

- [ ] 六个区域显示正确。
- [ ] 已解锁与未解锁区域有图标和文字区别。
- [ ] 地图路径和当前儿童位置可见。
- [ ] 点击区域可查看进度和下一步建议。
- [ ] 成长星达到阈值后可解锁区域。
- [ ] 已解锁区域不会因中断重新锁定。
- [ ] 钱包数字在页面间同步。
- [ ] 宝箱进度随奖励增加。
- [ ] 等级经验达到上限后升级。

## G. 成长档案与数据

- [ ] 周报数字来自当前状态。
- [ ] 完成任务会写入历史记录。
- [ ] 完成预习会写入历史记录。
- [ ] 完成专注挑战会写入历史记录。
- [ ] 徽章有已解锁和未解锁状态。
- [ ] 可导出全部成长数据。
- [ ] 可重置演示数据。
- [ ] 重置操作有二次确认。
- [ ] 页面刷新后数据不丢失。

## H. API 与安全

- [ ] `file:` 协议下自动使用离线模板，不发出模型请求。
- [ ] `http:` / `https:` 协议下自动请求同源代理。
- [ ] 代理不可用时自动回退到本地模板。
- [ ] API Key 不出现在前端文件。
- [ ] `.env.example` 不包含真实密钥。
- [ ] 任务接口限制数量、时间、难度和奖励。
- [ ] 预习接口强制补齐六步。
- [ ] 模型输出不以 HTML 直接插入页面。
- [ ] 用户文本插入 HTML 前经过转义。
- [ ] 服务端限制请求体大小。
- [ ] 服务端具有基础限流。
- [ ] 缺少教材时标注“待家长核对”。
- [ ] 错误信息不暴露密钥或系统堆栈给孩子。

- [ ] 1440 px 桌面无横向溢出。
- [ ] 1024 px 平板布局可用。
- [ ] 390 px 手机主导航显示在底部。
- [ ] 手机端卡片转为单列。
- [ ] 手机端模态框可滚动且不溢出。
- [ ] 地图节点在手机上重新排列。
- [ ] 触控按钮点击区域足够大。
